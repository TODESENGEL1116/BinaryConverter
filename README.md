# 进制转换与编码演示工具

这是一个基于 C 语言开发的命令行工具

## 主要功能

### 1. 整数编码分析
支持 **8位 / 16位 / 32位** 字长的整数处理：
- **十进制转二进制**：输入十进制整数，输出其对应的**原码**、**反码**和**补码**。
- **二进制转十进制**：
  - 正数/负数绝对值解读。
  - **补码解读**：输入补码形式的二进制串，解析其代表的真实十进制数值（支持负数）。

### 2. IEEE 754 浮点数转换
支持单精度 (`float`) 和双精度 (`double`) 两种标准：
- **十进制转二进制**：输入浮点数（如 `3.14`），输出其在内存中存储的 32位 或 64位 二进制机器码。
- **二进制转十进制**：输入二进制机器码，反向解析出对应的浮点数值。
